# 🤖 DataPilot AI Agent

> An AI-powered data analyst built entirely in Google Colab that automates data quality assessment, exploratory data analysis (EDA), business intelligence reporting, interactive dashboards, natural language querying, and executive PDF report generation.

---

## 📖 Overview

DataPilot AI Agent is an end-to-end data analytics project that demonstrates how Artificial Intelligence can automate the workflow of a data analyst.

Developed entirely in a Google Colab notebook, the project transforms raw datasets into actionable business insights through automated data profiling, interactive visualisations, AI-assisted querying, and executive reporting.

This repository contains the complete implementation notebook, project assets, screenshots, and a demonstration video showcasing the application workflow.

---

## ✨ Features

- 📂 Upload CSV and Excel datasets
- 🧹 Automated data cleaning and preprocessing
- 📊 Data quality assessment and health scoring
- 📈 Automated Exploratory Data Analysis (EDA)
- 📉 Interactive business dashboards
- 🌍 Regional sales analysis
- 🛍️ Product performance analysis
- 👥 Customer segmentation analysis
- 📊 Correlation analysis
- 🤖 AI-powered natural language data analysis
- 📄 Executive PDF report generation
- 💡 Automated business insights and recommendations
