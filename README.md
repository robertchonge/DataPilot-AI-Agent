# 🤖 DataPilot AI Agent

DataPilot AI Agent is an end-to-end AI-powered data analysis project developed entirely in a Google Colab notebook. It automates data quality assessment, exploratory data analysis (EDA), business intelligence reporting, and natural language interaction with datasets.

The repository includes the complete Jupyter notebook (`.ipynb`) containing all implementation phases, along with a demonstration video showing the application in action.

## 📂 Repository Contents

- 📓 Complete Google Colab notebook (`.ipynb`)
- 🎥 Demonstration video
- 📊 Sample dataset
- 📄 Generated reports
- 🖼️ Application screenshots
